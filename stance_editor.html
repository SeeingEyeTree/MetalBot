Stance Editor

Click a unit to add it. Set each unit's share of the army spend; shares always total 100%. Typing or dragging one share rescales the other unlocked units in proportion. The padlock keeps a unit's share fixed.

Units / 1000 M is what the controller will aim for: the metal-equivalent value (metal + energy/70) of each unit is divided into its share of spend.

The overall army share is not set here. The notes boxes explain the stance to whoever implements it.

Load opens a saved .json or a stance .lua from stances/. Save JSON keeps everything for re-editing. Export Lua writes the file the bot reads (put it in stances/). Run python extract_unit_data.py to refresh units and pictures from your installed BAR. Autosaves to this browser.
